# Frontend - Sistem Donasi & Keuangan PP Annuqayah Latee

Aplikasi antarmuka web (Portal Desktop & Responsive Mobile) berbasis React 19 dan Vite untuk Sistem Donasi dan Keuangan PP Annuqayah Latee.

## 🚀 Panduan Instalasi & Menjalankan

### 1. Install Dependensi
```bash
npm install
```

### 2. Jalankan Server Development
```bash
npm run dev
```

Aplikasi web dapat diakses di `http://localhost:5173`.

### 3. Build untuk Produksi
```bash
npm run build
```

Hasil build akan tersimpan di direktori `dist/`.

## ⚙️ Konfigurasi Proxy API
Proxy API ke server backend dikonfigurasi melalui `vite.config.js` mengarah ke `http://127.0.0.1:8000`.
